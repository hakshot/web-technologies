# Module 3 solution — Food, LLC

Responsive restaurant menu for Canvas Web Technologies, assignment 5.

Open `index.html` in a browser. Bootstrap 3.4.1 and jQuery 3.7.1 are stored locally, so the page also works offline.

## Files
- `index.html`: semantic page structure, Bootstrap navbar and grid, Chicken / Beef / Sushi sections.
- `css/styles.css`: page styling and mobile adjustments.
- `css/bootstrap.min.css`, `js/bootstrap.min.js`: Bootstrap 3.4.1 (MIT).
- `js/jquery.min.js`: jQuery 3.7.1 (MIT).

## GitHub Pages
1. Add the `module3-solution` folder to a GitHub repository.
2. In repository Settings → Pages, select Deploy from a branch, then the branch and `/ (root)` directory.
3. Open `https://USERNAME.github.io/REPOSITORY/module3-solution/`.
4. Submit the repository URL and published page URL to Canvas assignment 5.
